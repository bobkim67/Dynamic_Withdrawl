## 차후 개발 예정 (v4.1)

### 1. Tab 1 메커니즘 시각화 강화
- **현재 문제**: Fixed vs Guardrail 월별 인출 패턴 비교가 너무 단순한 케이스만 보여줌
- **개선 방향**:
  - 상승장에서 Fixed보다 많이 인출하고, 하락장에서 덜 인출하는 차이를 확실하게 보여주는 그래프
  - 이렇게 인출함으로써 달성하는 성공률(원하는 말잔잔고 유지) 시각화
  - 최종 누적인출금이 더 많다는 것을 보여주는 시각화 추가
- **영향 범위**: `render_tab_intro()` 내 메커니즘 차트 섹션

### 2. Beta 위젯 위치 재배치
- **현재 문제**: 왼쪽 사이드바의 beta 위젯과 연결되는 컨텐츠가 적음
- **개선 방향**:
  - 사이드바에서 beta 위젯 제거
  - beta와 연결된 각 컨텐츠 섹션 상단에 인라인 beta 위젯 배치
  - 사이드바에는 path_method, 포트폴리오 필터 등 글로벌 필터만 유지
- **영향 범위**: `main()` 사이드바 + 각 탭 render 함수

### 3. Beta 값 확장 (그리드 서치 재실행 필요)
- **현재 문제**: 실제 grid_results_full.pkl 데이터에 beta 0.1, 0.5, 1.0만 존재
- **개선 방향**:
  - grid_search.py CONFIG에 beta=[0.1, 0.25, 0.5, 0.75, 1.0] 추가
  - grid_search.py 재실행하여 pkl 재생성
  - viewer.py의 BETA_LABELS는 이미 5단계 준비 완료
- **영향 범위**: `grid_search.py` CONFIG + pkl 재생성 (소요 시간 증가 예상)
- **참고**: 결과 수 6,750 → ~11,250 (약 1.67배)

### 4. 모든 시각화에 핵심 코멘트 추가
- **현재 문제**: 일부 차트에만 코멘트 존재, 일관성 부족
- **개선 방향**:
  - 모든 시각화 그래프 위 또는 아래에 핵심 코멘트(해석 가이드) 추가
  - `_finding_box()` 헬퍼 적극 활용
  - 데이터 기반 동적 코멘트 생성 (예: "현재 선택 조합에서 Guardrail이 +X%p 우위")
- **영향 범위**: 전체 탭 render 함수

### 5. Band Trade-off 비교 그래프 추가
- **현재 문제**: Tab 3에 Band Trade-off 비교가 테이블만 있고 그래프가 없음
- **개선 방향**:
  - 성공률↑ vs 인출금↓ trade-off를 시각적으로 보여주는 scatter plot 또는 bar chart 추가
  - X축: 성공률 개선폭, Y축: 인출금 감소폭, 색상: Band 종류
  - 인출률 6%/8%/10%/12% 기준 포인트 표시
- **영향 범위**: `render_tab_band_analysis()` 내 Trade-off 섹션

### 6. 전략 상세 + 나의 전략 조합 탭 통합
- **현재 문제**: Tab 5(나의 전략 조합)와 Tab 6(전략 상세)이 기능적으로 분리될 필요 없음
- **개선 방향**:
  - 두 탭을 하나로 통합 (6탭 → 5탭)
  - 전략 조합 선택 → 지표 비교 → NAV 시뮬레이션을 하나의 흐름으로
  - 탭 이름: "나의 전략" 또는 "전략 탐색 & 상세"
- **영향 범위**: `render_tab_explorer()` + `render_tab_detail()` 통합

### 7. 분석 데이터 테이블 탭 추가
- **현재 문제**: 이전 분석에서 나왔던 핵심 데이터가 시각화에 충분히 반영되지 않음
- **포함할 데이터 테이블**:
  1. **Beta별 Guardrail vs Fixed 비교** (과거 백테스트 / Block Bootstrap 분리)
     - 포트폴리오 × 인출률 × Beta별 성공률 비교, 차이값 강조
  2. **과거 백테스트(Rolling) vs GBM vs Block Bootstrap 비교**
     - 3종 방법론 성공률을 나란히 비교하는 상세 테이블
  3. **핵심발견 요약**
     - 주요 인사이트를 조건별로 정리한 참조 테이블
- **구현 방식**: 새 탭 추가 (탭 이름: "분석 데이터" 또는 "상세 비교표")
- **영향 범위**: 새 `render_tab_data_tables()` 함수 + main() 탭 추가
