## 2차 작업: 실사용 피드백 10건 반영

### 피드백 & 처리 내역

1. **산점도 Pareto frontier 선 제거**
   - 포트폴리오끼리 이어지는 점선(눈금) 삭제
   - 90% 성공률 기준선은 유지

2. **Fixed vs Guardrail 범례 구분 강화**
   - ◇ 다이아몬드 = 고정 인출
   - ● 원형 = Guardrail (크기 = Band 폭 비례)
   - 포트폴리오별 "고정" / "Guardrail" 별도 trace로 분리

3. **Band 범위 필터 삭제**
   - 필터 컬럼 3개 → 2개 (포트폴리오, 전략 모드)
   - 관련 로직 전부 제거

4. **전략선택 (Tab 3 연동) 섹션 삭제**
   - expander + selectbox + button 전체 제거

5. **초기인출률 곡선 + 히트맵 세로 배치**
   - 2열 side-by-side → 1열 세로 스택
   - 차트 높이 380 → 450/400으로 확대

6. **잔액경로 시뮬레이션 path_method 연동**
   - simulate_paths_for_strategy()에 path_method 파라미터 추가
   - rolling / bootstrap / combined 각각 경로 생성
   - sim_key에 path_method 포함하여 캐시 키 갱신

7. **인출률 시계열 fan chart 변환**
   - 기존: P5-P95 1개 밴드 + median
   - 변경: P5-P95 (연한) + P10-P90 (중간) + P25-P75 (짙은) 3단계 fan chart

8. **전 전략 Fixed vs Dynamic 비교 히트맵 추가**
   - 포트폴리오 × 초기인출률 조합별 추가인출(%) 히트맵
   - Greens colorscale, 짙을수록 Guardrail 효과 큼

9. **Guardrail 인출률 범위 섹션 삭제**
   - Bar + hline 시각화 섹션 전체 제거

10. **NAV 경로 엑셀 다운로드 추가**
    - NAV_Monthly 시트: 경로별 월별 잔액
    - Withdraw_Monthly 시트: 경로별 월별 인출액
    - 기존 전략 결과 다운로드와 나란히 2컬럼 배치
